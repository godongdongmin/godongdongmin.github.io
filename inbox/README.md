# 자료 입력 공간 — 로컬 전용

CV/홈페이지 수정을 위한 파일을 다음 폴더에 넣고, 반영할 내용과 경로를 작업자에게 알려주세요.

- `awards/`: 수상 자료
- `education/`: 학력·성적 자료
- `photos/`: 사진 후보
- `research/`: 연구 관련 참고 자료
- `references/`: 참고 CV·디자인
- `notes/`: 수정 요청이나 개인 메모

폴더 구조와 이 안내문만 GitHub에 올라갑니다. 넣은 자료는 Git과 배포 ZIP에서 제외되므로 **다른 PC로 자동 동기화되지 않습니다.** 자동으로 홈페이지에 반영되지도 않습니다.

확인한 공개 정보는 `source/profile.json`에 입력하고, 공개할 사진·영상만 `assets/`, `files/`로 옮깁니다. 업로드할 의도가 없는 파일에 `git add -f`를 사용하지 마세요.
