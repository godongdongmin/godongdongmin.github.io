# Dongmin Go — Academic Homepage

A lightweight academic homepage built with static HTML and CSS.

- `index.html`: homepage
- `assets/style.css`: responsive styles
- `assets/portrait.jpg`: profile photograph
- `files/Dongmin_Go_CV.pdf`: curriculum vitae
- `research/myomimetic-exosuit/index.html`: manuscript overview and video
- `files/myomimetic-exosuit-video.mp4`: supplementary video
- `.nojekyll`: serve the site as plain static files

To publish, use the repository `godongdongmin/godongdongmin.github.io` and configure GitHub Pages to deploy from `main` and `/(root)`.

The page works without JavaScript, external fonts, analytics, or a build service. Profile text and imagery belong to their respective owner.
